# v0.0.1 — first npm release

First public npm release of the anysearch suite. **Manual first release** —
published by hand (`pnpm -r publish`), so **no npm provenance attestation** is
attached (ADR-0064 D-006). This is a known consequence of the release model,
not a defect: provenance requires a cloud-hosted runner; the registry-side
checks (version, dist-tags, access, repository) are verified post-publish per
docs/publishing.md.

## Packages

- `@anysearch/cli@0.0.1` — `ans` CLI (search / research / memory / knowledge)
- `@anysearch/mcp@0.0.1` — MCP server (`ans_*` tools, stdio + HTTP)
- `@anysearch/plugin@0.0.1` — host-agent plugin (hooks + adapters)
- `@anysearch/embedding@0.0.1` — optional vector arm (**peer-optional**: never
  auto-installed; `npm i -g @anysearch/embedding` enables it)

Internal packages (`kernel`, `store`, `retriever`) are bundled into the apps'
`dist` and are not published (bundled-CLI shape, ADR-0064 D-005).

## Highlights

- Domain allowlist with dual-gate filtering + first-class abstain (ADR-0062)
- Offline-deterministic memory eval: 126/126 golden cases, fingerprint
  `4a529f6fbe2096c8`
- Apache-2.0 license

## Fixed since the R62 audit

- Consolidation dedup now works without the embedding arm: Jaccard lexical
  fallback (θ=0.80) when no cosine is computable; degraded decisions counted in
  `ConsolidateReport.embeddingAbsent` (ADR-0064 T1 / D-002).

## Known limitations (abridged — see README)

- Page-level `mustHitUrl` live assertions: 10 of 12 live golden entries are
  quarantined for provider URL-shape drift (TTL 2026-10-14, shrink-only
  ratchet). Host-level evidence 12/12; active live legs = 1 host-level +
  1 abstain verdict.
- macOS is a non-blocking spillover-probe lane (exit-time `libc++abi` family);
  probe data point #1 additionally showed a registration-segment red.
- On Windows the exit-time `libc++abi` crash can overwrite the abstain exit
  code — automation must read the structured `abstain` field.
