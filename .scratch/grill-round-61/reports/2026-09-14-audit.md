## 4. 发现清单（按严重度）

**F1（高，需裁决）** CLI abstain 退出码在 Windows 上间歇被进程 teardown 崩溃改写：libuv `UV_HANDLE_CLOSING` 断言 → exit 0xC0000409。实测 abstain.test.ts live arm 连跑 2 次各挂 1 条断言（默认 exit 0 臂、--fail-on-abstain 臂各中一次）；审计另跑 8 次子进程全净 → 间歇性，非确定性。报告遗留项称"exit code 不受影响"——**实测证伪**。根因 pre-existing（Windows Node+better-sqlite3 句柄退出怪癖），但它正中 T3 核心契约（禁 exit 非零默认）。处置建议：呈报用户裁决——(a) 打回修复窗口做 teardown 根因票；(b) 立专项缺陷票+改正报告/README 措辞（Known Limitations 目前未载此条对 exit code 的影响）。

**F2（中，已披露但属 mandatory 未达）** 判据5 Tavily include_domains 泄漏探针四臂全 SKIPPED。ADR-0062 明文 "promoted to mandatory"。缓解：探针脚本/账本/复跑命令齐备、SDK 透传已源码级证实。strictly 此判据未闭合，轮次收口依附于用户接受该 deferral。
