## 实物裁决与偏离记档

1. **defineTool→裸 ToolDefinition**（D-001 字面偏离，ADR-0091 D1 记档）：defineTool 是 @deepseek-ai/dsh-tools 运行时值——运行时导入破 dependencies:{} 零依赖契约；裸字面量消费同一 ToolRuntime.register 契约且 KernelJsonSchemas 逐字投影零损（DSL 不表达 additionalProperties:false/minLength/minimum）。参数校验留服务端 TypeBox SSOT。
2. **execute 落点**：plugin server(33333) 无工具路由→真后端=ans-mcp HTTP /mcp（无态 JSON-RPC，每请求独立 Server 实例）；进程级握手缓存按 base|token 键，session 错(-32001/-32600)重握手一次。
3. **callServer 同契约延展**：+headers/+timeoutMs/+signal 加性槽位+空体 2xx→{}（通知帧正当形态）；既有调用点零行为变化。
4. **ship-gate 断言进化**（T4 同票）：cordis.patch.yml 由「必须含桥行」翻转为「禁活桥行+查 src/index.ts 原生面八锚」——revert T4 则断言同复旧观。
5. **测试基础设施事实**：@anysearch-cli/plugin 的 exports default 指向 dist/*.cjs——hooks 层源码改动须先 pnpm build 才对测试可见（T3 首跑红根因）。
