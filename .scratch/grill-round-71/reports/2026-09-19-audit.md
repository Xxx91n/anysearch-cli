## 5. 发现清单

- **F1（实质缺陷，建议返工）**：`packages/store/src/embedding-arm.ts:79,82` — `await import(direct)`/`await import(sib)` 无保护。resolve 成功但 import 失败（损坏 dist、缺 chunk、顶层 ESM 错）→ rejection 上抛且 `modPromise` 永久缓存拒绝态 → `embedText`/`armTelemetry`/`embeddingModelId` 全生命周期抛错 → `searchMemory`(:614)、`adjudicateMemory`→`embedWrite`(:740,757)、`backfillEmbeddings`(:845)、`vectorTelemetry`(:796→doctor) 四路径无 catch 全炸，且首候选失败会中止其余锚点扫描。违反本文件头契约（"arm absent ⇒ embedText ≡ null"）、ADR-0033/0063 fail-open、CONTEXT.md「写库必须永远成功」。测试 16 断言无此用例。
  最小修复：每候选 `try { return await import(...) } catch { continue; }`（既守 fail-open 又不中止其余锚点）+ 测试补「resolved-but-broken sibling」用例。重跑清单：`pnpm -C packages/store test` + `pnpm build` + `node scripts/install-smoke.mjs`。
- **F2（文档缺口，小）**：`doctor.ts:69` enable 指引仅 `npm i -g`；断的是 pnpm 臂。建议给 `npm i -g` / `pnpm add -g` 两行。
- **F3（固有缘，建议 ADR 注记）**：`inRepo()` 以本机 ROOT 判库内引用——他机写来的绝对库内路径在本机归入 out-of-repo（marker 可豁免），跨机弱化"in-repo refs must be repo-relative"。
- **F4（判定项）**：`ship-gate-pathlint.config.json` `marker` 字段死配（MARKER_OK/MARKER_ANY 硬编码于 ship-gate.mjs:1051-52）——接线或删除，否则配置即漂移饵。
- **F5（判定项）**：`globOk` 遇不支持 glob 形退化精确匹配→静默零扫；fail-closed 腿内建议 `fail()` 于不可解析 pattern。
- **F6（cosmetic）**：数字口径漂移（报告 317 refs/93 markers vs commit 322/90 vs 现树 106——时点量测非矛盾）；fixture 版本 `0.0.5`；文档内 `evidence\` 反斜杠；deferred-registry 尾换行丢失；TOKEN_RE 字符类 ×3；index.ts `createRequire` ×2。
