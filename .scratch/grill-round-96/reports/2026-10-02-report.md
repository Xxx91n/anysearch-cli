## 3. F8 三缺陷闭环逐条

### F8-a 模板↔门禁 PENDING 冲突

- **缺陷**：`docs/agents/handoff-template.md` 允许「PENDING — stack unpushed」的诚实写法，而门禁恒要求至少一条 `actions/runs/<id>` URL——诚实者恒红、不诚实者恒绿。
- **修法**：模板与门禁同轮同语法（T3 + T1/T2）。run-URL 字段改**一条显式状态行**：`GREEN: <url>...` 或 `PENDING: <code>`；散文/旁注 URL 不再满足字段。
- **机检证据**：claims `r96-t3-template-grammar`（symbol，模板含 `PENDING: stack-unpushed` / `pushed-no-branch-runs` / `round >= 96` / `green-claim-falsified`）；单测 D 节 `a prose PENDING with a URL yields no state line (F8-b)`。

### F8-b liveness 静默折叠 + 祖先性冒充

- **缺陷**：`gh`/repo 不可用时该腿打印 `(liveness leg skipped)` 后仍报 pass；「本轮 run」判等用 `merge-base --is-ancestor <sha> HEAD` 的祖先性冒充栈内成员性（main 基线 run 天然满足）；等值目标用裸 `rev-parse HEAD`（GitButler workspace 合成 commit 自指悖论）。
- **修法**：GREEN 四条件＝栈内成员性（`head_sha ∈ git rev-list origin/main..origin/<branch>`）∧ success ∧ workflow ∈ {ci, ship-gate} ∧ repo 匹配；环境不可得时改 env-PENDING + 具名降级码（`verification-unavailable:{gh-missing|repo-parse|api-failed|ref-unavailable}` / `stack-unavailable` / `ref-unavailable` / `shallow-clone`）。**审计纠正（P1）**：初版此处写「永不静默」**不成立**——B1/B2 坐实环境不可用时报 verified（比静默更糟）。返工后两条腿均先读 `env.git.ok` / `env.workflows.ok` / 事实图存在性，「未读到的事实」一律降级，且降级标注已进入报告行（`pendingSummary` 同时携带声明码与降级码）。
- **机检证据**：claims `r96-t2-ancestry-hack-removed`（count，ship-gate 内 `is-ancestor` 计数=0）与 `r96-t2-revparse-head-removed`（count，裸 `rev-parse HEAD` 计数=0）；fixture `green-ancestor-run-rejected`（main 基线 run → RED `green-claim-falsified`）；fixture `prose-url-only-rejected`（旁注 URL → RED `run-url-state-line-missing`）；fixture `gh-missing-degraded` / `gh-api-failed-degraded`（env-PENDING + 具名码）。

### F8-c CI 拓扑使必填字段物理不可满足

- **缺陷**：三 workflow 触发器=`push: branches: [main]` / `pull_request` / `workflow_dispatch`，特性分支 push 恒不产出 run，故「本轮 run URL」在特性分支上无解。
- **修法**：`PENDING: pushed-no-branch-runs`（谓词＝ref 存在 ∧ 无 workflow 的 `on.push` 覆盖该分支）＋`PENDING: stack-unpushed`（谓词＝无 `origin/<branch>` ref）——两者均为门禁**离线自证**的可机械判定状态；词表封闭，扩词表须改门禁代码。
- **机检证据**：E2E D 节真实仓库断言 `F8-c: no workflow covers a push to a feature branch`（`collectWorkflowTriggers(root).pushBranches=["main"]` 且 `pushAllBranches=false`）与 `a tags-only push trigger does not count as branch coverage`（release.yml）；fixtures `pending-pushed-no-branch-runs-verified` / `-conflict`。

## 4. 实现裁量回报（账本外裁量三件）

1. **增设薄壳模块**：D-004 只点名「判定核纯模块 + ship-gate 薄壳」。落地时把采集与编排抽为 `scripts/handoff-lint-shell.mjs`（采→传→出口），ship-gate 只做目标选取与调用——理由：壳内要能被 E2E 以同形状注入驱动，否则「锁接线」只能测到纯核。已写入 ADR-0097 D3。
