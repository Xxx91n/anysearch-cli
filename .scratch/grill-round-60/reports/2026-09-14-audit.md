## 3. 发现（呈报裁决，审计不代追认）

- **F1（spec §4.4 弱化/实质未接线）**：`url-policy.ts domainTomlPath` 新增 `extraDomainsDirs` 参数但**零调用方传入**，ANS_DOMAINS_DIR 从未被该层读取；plugin `server/index.ts:36`、`chat.ts:80`、`ans-chat.tool.ts:56`、`hitl.ts:38` 仍 cwd-only。与 G1 所修「留了 API 面没留行为」同型。
- **F2（解析链只在 search 面接通）**：`chat.ts:57`、`memory-preference.ts:50` 走 kernel `createEngine` 缺省 `defaultDomainsDirs()`（仅 env+cwd 两链）；`apps/mcp server.ts:35` 同。安装物上 `ans chat`/`ans pref`/`ans-mcp` 对 docs 域仍 silent full-fanout。双链并存（domainSearchDirs 4 链 vs defaultDomainsDirs 2 链）属 shotgun-surgery 债，根因=解析链未单一化为共享模块。
- **F3（诚实性工件数据失准）**：coverage manifest classes 算术错——source-tier reference 实 4 记 3（classes 和 9≠count 10）；freshness stable 实 5 记 6（classes 和 12≠count 11）。`crossCheckDocsGolden` 只校 count 不校 classes → 绿灯放行。count 本身与实际相符。
- **F4（T2 判据弱化）**：「离线 golden CI 绿（快照 fixture）」无快照回放实现；offline 腿=文档化行为断言；golden.expected 无执行器。D-002「首轮只记录不设阈」部分豁免；报告自述「offline 断言文档化行为」未虚报。
- **F5 微瑕清单**：urlAllowlist 增裸域 `typescriptlang.org`（spec 附表 3 源→实际 4，属小幅越界）；backfill `--new` 分类默认（intent=troubleshoot/lang=zh）+ 硬编 internal-dogfood；三处台账 writeFileSync 非原子（repo 惯例 tmp+rename，url-policy.ts:124）；doctor `mkdirSync` 副作用 + `fileURLToPath` 死 import；engine uniqueUrls 原始 url 计数 vs normalizeUrl 去重口径不一；toml 列表块重复 ×3（domain.ts 两处 + doctor.ts 一处）。
- **子代理误判纠正**：Spec 轴称「ship-gate step1c 只断言声明未断言接线」——**伪**。ship-gate.mjs:568 实断 `graceExpired` + `controllers[j].abort()` 源码级接线态（非行为级，配合 engine.test 行为断言仍属有效哨兵）。
