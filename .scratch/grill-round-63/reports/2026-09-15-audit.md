## 逐项发现（缺失/弱化/跑偏）

### 需呈报用户裁定（文档/声明级）

- **A（中）publishing.md min-release-age 声明失实**：.npmrc `min-release-age=2` 对 npm 11.6.1 是 Unknown project config（warn+忽略）；pnpm 侧键名亦不符（pnpm 用 minimumReleaseAge/`minimum-release-age`，pnpm-workspace.yaml 无此键）。故"npm i -g 前两天不可见"不成立、`--min-release-age=0` 覆盖为空操作。72h 窗自验按精确版本装仍可行。该行系 scaffold 存量（77daab4），非本轮引入；spec D-006 原措辞本身带此假设——fixer 忠实实现了带事实错误的 spec。
- **B（中）README:8 `Status: 0.0.1 on npm` 超前于证据**：npm view 404。若按执行票序 land 先于 publish 完成，main 上将携带不实 status。建议改 "release in flight" 或确认 publish 完成后再落该行。
- **E（低）VERDICT 标签**：doc 写 GO，但本轮词表（CONTEXT.md:938 GO WITH CAVEATS）正是为此态所立（6 带病项 minuted）。实质内容正确（doc 自称 GO with execution preconditions），标签精度差。

### 建议硬化（可一行级返工或下轮）

- **C（低-中）ship-gate step5 bare-require 断言格式洞**：`/(?:require|import)\s*\(/` 只抓调用式；静态 `import/export ... from "@anysearch-cli/x"` 逃逸。当前 3 app 全 CJS 产物无现实风险；任一翻 ESM 即静默失防。
- **D（低-中）ratchet 断言3 按 flag 短路而非裁决记录**：API 路径 flag⟺reviews 记录同源写入（retireEntry/longtermEntry 两处同写），故现状等价；但手改 JSON 只立 flag 可逃逸，且 longterm cap 只数 flag——reviews 里的 longterm 记录无 flag 则逃逸 cap。另 Date.parse NaN→过期检查静默假（fail-open 方向错）。
- **H（微）probe-tavily-domains.mjs:4 头注仍写 round-61 输出路径**（OUT_DIR 已改 round-62）——陈旧注释。
