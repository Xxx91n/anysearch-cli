## ADR-0056 Rejected 约束遵守

- ✅ 不引入 tracestate header（使用 x-anysearch-session-id，规避 32 键截断）
- ✅ 不建 sessions 表（trace/session/client 归因列内嵌 observability_traces）
- ✅ 不向上游 backends 携带 x-anysearch-session-id（仅 localhost loopback）
- ✅ 不引入独立 TTL 决策（materialized_at 仅作新鲜度参考，无自动 expire）

## Found / Fixed / Deferred

**Found**：
- 既有 emitConfigChangeAudit 调用点全部传 traceId/sessionId=""（OPA #6905 经典反模式）
- trace store schema 仅 7 列，无 session/client 归因
- policy.json 缓存无时间戳，无法区分新鲜与陈旧

**Fixed**（commit 已落到 feat/grill-56-session-id-propagation 分支）：
- emitConfigChangeAudit 默认生成 traceId + 读 sessionId 文件/env
- 新增 3 列 + 3 索引（2 partial + 1 normal）+ PRAGMA user_version v0/v1 双路径迁移
- 新增 session-id.ts 文件持久化（~/.anysearch-cli/session）+ ANS_SESSION_ID env override
- Hook 端 buildPropagationHeaders/Server 端 parseAndValidateHeaders 共享 wire format
- MCP clientInfo → client_id Railway 映射表 + AsyncLocalStorage 上下文传递
- writePolicyCache materialized_at + 启动降级 WARN

**Deferred**：
- server.startup WARN 频次降噪（多 hook 同时启动可能触发多次 WARN；下轮加 cooldown）
- ANS_SESSION_ID 与 ANS_DB_PATH 的多层 env override 一致性（kernel composition 已有 ANS_DB_PATH，可下轮合并接口）
