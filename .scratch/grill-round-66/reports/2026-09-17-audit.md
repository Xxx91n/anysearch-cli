## 二、发现（按严重度）

### F-01【硬伤·返工】ship-gate 版本钉未随 bump 更新
- scripts/ship-gate.mjs ~L216：step1a 断言每包 pkg.version !== "0.0.3" → fail；七包已全部 0.0.4 → 树在 HEAD 上 ship-gate 必红。
- 影响面：ship-gate.yml on: push/PR→main——r66 分支与 tag 推送均未触发它，release.yml 也不跑它；**首次 main 合入/推送即红**。同类纪律在 AGENTS.md 有先例（pnpm 双字段同 commit 钉）。
- 修复要求：pin 改 0.0.4（或改读单一事实源），与 bump 同纪律。重跑：node scripts/ship-gate.mjs 全绿（注意 F-01a）。
- F-01a【环境观察】ship-gate step0 clean-tree 读 git status --porcelain——GitButler workspace 下恒脏（索引工件），本地 but 会话内永远过不了 step0；CI 净克隆无此问题。建议记录，必要时给 ship-gate 加 but-workspace 豁免。

### F-02【硬伤·返工】漂移守卫形同虚设（双轴+亲验一致）
- apps/plugin/test/claude-contract.test.ts:131-147：第一次 spawnSync 先重生成被跟踪文件，再读 before → deepEqual(after,before) 只能证明 regen#1==regen#2，**永远不能发现手改漂移**；且测试有写源树副作用（静默覆盖手改）。mkdtempSync 的 tmp 建了不用（死代码，暴露原意是 regen-to-temp 比对）。
- 与 ADR-0067 D2 "drift guarded by regen-identical contract test" 的声明不符。
- 修复要求：先快照 before 再 regen；或 regen 到 tmp 目录逐字节比对。修后必须演示一次真红（手改 hooks.json → 测试 fail）作先红后绿证据对。

### F-03【记录或修】session-start.cjs 跨宿主形状变更未入账
- session-start.cjs 被 5 宿主模板共享（claude/codebuddy/codex/cursor/antigravity 的 SessionStart 均指向它）；R66 改其只发 hookSpecificOutput 信封。codex.ts PostToolUse 仍发裸 additionalContext（codebuddy-contract.test.ts ~L180-188 钉死），Codex 无 .mdc 兜底（ensureMdc 只写 .cursor/rules）——若 Codex 只认裸字段，Codex SessionStart 注入静默死。
- Codex/Cursor/Antigravity 均未实测、属范围外，属契约级风险而非 live 缺陷；但变更未在 defect-ledger/ADR 记录 → ADR-0029 未记录顺手改。处置任选：deferred 入账 / 信封+裸字段双发 / 按宿主拆 session-start。
